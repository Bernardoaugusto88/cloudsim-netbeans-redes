# Projeto CloudSim - Redes

## Sobre o projeto

Projeto acadêmico desenvolvido para a disciplina de Computação em Nuvem, com o objetivo de criar um projeto Java no Apache NetBeans e executar uma simulação utilizando o framework CloudSim.

A atividade utiliza o exemplo `CloudSimExample1`, fornecido pelo CloudSim, para demonstrar uma simulação básica de recursos de computação em nuvem.

## Objetivos

- Criar um projeto Java utilizando o Apache NetBeans.
- Configurar o ambiente para utilização do CloudSim.
- Adicionar a biblioteca CloudSim ao projeto.
- Executar o exemplo `CloudSimExample1`.
- Observar e analisar os resultados da simulação.
- Registrar as etapas de desenvolvimento e execução do projeto.

## Tecnologias utilizadas

- **Java**
- **Apache NetBeans IDE 31**
- **CloudSim 3.0.3**
- **JDK 25**
- **Git**
- **GitHub**
